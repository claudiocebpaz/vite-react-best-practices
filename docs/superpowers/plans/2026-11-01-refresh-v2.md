# Vite React Best Practices v2.0.0 Refresh — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refresh all 11 skill rules and supporting docs to the November 2026 React/Vite ecosystem and ship version 2.0.0.

**Architecture:** Three parallel content agents (one per category, disjoint files) followed by one sequential integration agent that regenerates the compiled guide and metadata. No structural changes, no build system.

**Tech Stack:** Markdown skill files. Target content stack: React 19.3, Vite 8.3 (Rolldown), React Router 8.5, TanStack Query v5 (5.105.1), strict TypeScript. React Compiler v1+.

**Spec:** `docs/superpowers/specs/2026-11-01-refresh-v2-design.md`

---

## Shared content contract (applies to every rule edit)

Every file under `rules/` must end up with:

1. YAML frontmatter:
   ```yaml
   ---
   title: <Rule Title>
   impact: CRITICAL | HIGH | MEDIUM | LOW
   tags: tag1, tag2, tag3
   ---
   ```
2. The existing H1 kept below the frontmatter.
3. Body format preserved: brief intro, `## Why it matters`, `## Incorrect`, `## Correct`
   with fenced code blocks that declare a language (`tsx`, `ts`, `bash`, `nginx`, `json`, `toml`, `http`, `env`, `yaml`).
4. A final `## References` section with 2-4 official links.
5. English, no emojis, no Next.js/RSC/server-actions content.
6. Facts verified against official docs at edit time; no unverified version claims.
7. File name and H1 do not change (SKILL.md links rely on file names).

Recommended impacts: deployment rewrites/caching = `CRITICAL`; build validation/env vars = `HIGH`;
route splitting/server state = `HIGH`; memoization/images/colocation/dist/troubleshooting = `MEDIUM`.
